# menu-file-compare
# Excel & ODS Comparator (Сверка табличных файлов)

Интуитивно понятная утилита с графическим интерфейсом (GUI) на **Tkinter** для взаимной сквозной сверки двух табличных документов. 

### 📐 Архитектура и масштабируемость
Главный модуль `main.py` спроектирован как **универсальная панель управления (диспетчер программ)**. Текущая архитектура позволяет легко масштабировать проект и расширять меню, добавляя новые независимые модули, скрипты автоматизации и утилиты без изменения логики самого интерфейса.

### 🎯 Целевая аудитория и бизнес-ценность
Функционал программы ориентирован на конечных пользователей Excel, которые **не владеют или по каким-то причинам не желают использовать сложные формулы вроде ВПР (VLOOKUP) / ИНДЕКС(ПОИСКПОЗ)**. Утилита позволяет сопоставить огромные массивы данных в пару кликов, исключая человеческий фактор и необходимость писать формулы вручную.

## 🚀 Основные возможности

*   **Мультиформатность:** Поддержка современных и старых форматов электронных таблиц: `.xlsx`, `.ods` (LibreOffice/OpenOffice) и `.xls`.
*   **Умный выбор листов:** Автоматическое определение и чтение данных с **активного листа** для форматов `.xlsx` на момент последнего сохранения файла.
*   **Безопасность данных:** Программа работает по принципу *Read-Only* для исходных документов. Результаты формируются во временной директории системы и открываются в живом окне вашего табличного редактора.
*   **Двусторонняя сверка:** Проверка выполняется в обе стороны (строки первого файла ищутся во втором, и наоборот).

---

## 📋 Инструкция по использованию алгоритма сверки

1.  **Ограничение по файлам:** В каталоге с программой должно находиться **строго 2 сверяемых файла** (`.xlsx`, `.xls`, `.ods`). Если файлов будет меньше или больше, программа выдаст графическое предупреждение и остановит работу.
2.  **Активный лист:** В каждом файле форматов `.xlsx` активным должен быть именно тот лист, данные которого необходимо сверить. *Для форматов `.xls` и `.ods`всегда считывается только первый лист книги.*
3.  **Правило двух столбцов:** Сверка ведется по **двум первым столбцам** каждого файла (значения этих столбцов склеиваются в уникальный сквозной ключ). Важно, чтобы последовательность соответствующих столбцов в обоих файлах совпадала. Если порядок столбцов иной, поменяйте их местами вручную перед запуском.
4.  **Сверка по одному столбцу:** Если вам необходимо выполнить сверку только по одному первому столбцу, обязательно добавьте в таблицу второй пустой столбец, чтобы структура ключа сформировалась корректно.
5.  **Результат работы:** Между 2-м и 3-м столбцом исходных таблиц программа добавит новый столбец с результатами проверки (`«Расхождений нет»` или `«Есть расхождения»`), а первая строка получит заголовок `«Результат сверки»`. Все последующие столбцы автоматически сдвинутся вправо.

## 💻 Порядок запуска программы

1.  Поместите исполняемый файл (или скрипт `main.py`) в одну папку с двумя вашими исходными таблицами.
2.  Запустите программу.
3.  В выпадающем списке выберите нужный алгоритм сверки: **"135 Сверка двух файлов по двум первым столбцам"**.
4.  Ознакомьтесь с появившимся в текстовом поле описанием требований и нажмите кнопку **"Запустить"**.
5.  Программа выполнит сверку в фоне и асинхронно откроет результаты в окнах вашего табличного редактора (например, LibreOffice Calc или Excel).

## 🛠 Технические требования и зависимости

Для запуска проекта из исходного кода вам понадобятся **Python 3.x** и следующие библиотеки:

```bash
pip install pandas openpyxl odfpy xlrd
```

*   `pandas` — для базовой работы со структурами данных.
*   `openpyxl` — движок для чтения/записи `.xlsx`.
*   `odfpy` — движок для резервного чтения таблиц OpenDocument (`.ods`).
*   `xlrd` — движок для чтения старых форматов Excel (`.xls`).

> **Примечание для Linux-пользователей:** Для корректного автоматического вывода результатов на экран в системе должны быть настроены утилиты `xdg-open` или установлен пакет `libreoffice`.

## 📂 Структура модулей проекта

*   `main.py` — модуль графического интерфейса пользователя (GUI) на Tkinter, отвечающий за выбор утилит и вывод описаний.
*   `p135_excel_worker.py` — внутреннее ядро программы. Содержит кастомный XML-парсер файлов `.ods` для точечного извлечения данных активного листа в обход стандартных ограничений Pandas, а также логику сквозного маппинга ключей.
